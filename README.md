# h1gfun4Vim IDE Guide
## Для установки моего конфига воспользуйтесь файлом `vim.sh`
## Основные горячие клавиши

### Навигация
| Комбинация       | Действие                          |
|------------------|-----------------------------------|
| `h`, `j`, `k`, `l` | Движение (←, ↓, ↑, →)            |
| `Ctrl+h/j/k/l`   | Переход между окнами              |
| `gg`             | В начало файла                    |
| `G`              | В конец файла                     |
| `}`              | Следующий абзац                   |
| `{`              | Предыдущий абзац                  |
| `w`              | На слово вперед                   |
| `b`              | На слово назад                    |
| `Ctrl+o`         | Вернуться к предыдущей позиции    |
| `Ctrl+i`         | Вернуться вперед по истории       |

### Работа с текстом
| Комбинация       | Действие                          |
|------------------|-----------------------------------|
| `v`              | Визуальный режим (символы)        |
| `V`              | Визуальный режим (строки)         |
| `Ctrl+v`         | Визуальный блок                   |
| `y`              | Копировать (yank)                 |
| `d`              | Удалить (delete)                  |
| `p`              | Вставить после курсора            |
| `P`              | Вставить перед курсором           |
| `u`              | Отменить (undo)                   |
| `Ctrl+r`         | Вернуть (redo)                    |
| `>>`             | Сдвинуть вправо                   |
| `<<`             | Сдвинуть влево                    |

### Продвинутое редактирование
```vim
" Выделить весь файл
ggVG

" Выделить абзац
vip  (визуальный режим + inner paragraph)

" Добавить курсор в начало каждой строки (блочное выделение):
1. Ctrl+v - войти в визуальный блок
2. j/k - выделить строки
3. I - начать вставку
4. Текст + Esc

" Удалить до конца строки
d$

" Копировать в системный буфер
"+y

" Вставить из системного буфера
"+p
```

## IDE-функции (через `<Пробел>`)

| Комбинация       | Действие                          |
|------------------|-----------------------------------|
| `<Пробел>`       | Терминал (переключение)           |
| `<Пробел>e`      | Файловый менеджер (NERDTree)      |
| `<Пробел>ff`     | Поиск файлов (FZF)                |
| `<Пробел>t`      | Панель тегов (TagBar)             |
| `<Пробел>fs`     | Сохранить файл                    |
| `<Пробел>qq`     | Выйти без сохранения              |
| `<Пробел>~`      | Открыть/закрыть терминал          |
| `<Пробел>1,2,3`  | Открыть конкретный терминал       |
| `gd`             | Перейти к определению (LSP)       |
| `gr`             | Показать ссылки (LSP)             |
| `<Пробел>rn`     | Переименовать переменную (LSP)    |

## Работа с историей изменений

### Древо изменений (Undo-Tree)
1. Установите плагин:
   ```vim
   Plug 'mbbill/undotree'
   ```
2. Горячие клавиши:
   ```vim
   nnoremap <leader>u :UndotreeToggle<CR>
   ```
   - Открывает визуальное дерево изменений
   - `j`/`k` - навигация по истории
   - `Enter` - вернуться к выбранному состоянию

### Альтернативный подход
```vim
" Перемещение по истории изменений
nmap <C-z> :earlier 1f<CR>  " Шаг назад во времени
nmap <C-y> :later 1f<CR>     " Шаг вперед во времени
```

## Советы

1. **Повторение команд**:
   - `5j` - перейти на 5 строк вниз
   - `3dd` - удалить 3 строки

2. **Макросы**:
   - `qa` - начать запись макроса в регистр `a`
   - `q` - остановить запись
   - `@a` - выполнить макрос

3. **Поиск**:
   - `/слово` - найти "слово"
   - `n`/`N` - следующее/предыдущее совпадение

4. **Мультикурсоры** (через LSP):
   - Выделите слово
   - `<Пробел>rn` для переименования во всех местах
```

## Установка доп. плагинов

Добавьте в `.vimrc` перед `call plug#end()`:

```vim
" Undo-Tree
Plug 'mbbill/undotree'

" Мультикурсоры
Plug 'mg979/vim-visual-multi'

" Автодополнение кавычек/скобок
Plug 'jiangmiao/auto-pairs'
```

После добавления выполните в Vim:
```vim
:PlugInstall
```
